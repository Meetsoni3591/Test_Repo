# Test Cases for T1.1.1 - Users Metrics

Okay, here are two detailed test cases based on the provided "Users Metrics" task.  These test cases focus on validating the core functionality of tracking and displaying user metrics, as well as the ability to edit the metric's description.

**Test Case 1: Verify Total Registered Users and New Registrations Metrics**

*   **Title:** Verify Total Registered Users and New Registrations Metrics are Accurately Tracked and Displayed

*   **Description:** This test case verifies that the system accurately tracks and displays both the total number of registered users and the number of new registrations (e.g., daily, weekly, monthly). This includes verifying that new user registrations correctly increment the 'Total Registered Users' count and that the 'New Registrations' metric accurately reflects the number of users who registered within the specified time period.

*   **Steps:**

    1.  **Pre-condition:** User needs to be logged in with Admin Access.
    2.  **Pre-condition:** No new registrations have occurred within the last 24 hours (for testing "New Registrations" daily).
    3.  **Navigate:** Log in to the application as an administrator.
    4.  **Navigate:** Access the "Users Metrics" dashboard or reporting page.
    5.  **Observe:** Note the current "Total Registered Users" count.
    6.  **Observe:** Note the current "New Registrations (Daily)" count.
    7.  **Action:** Register [X] new users through the standard user registration process. (Where X = 3)
    8.  **Navigate:** Refresh the "Users Metrics" dashboard or reporting page.
    9.  **Observe:** Note the updated "Total Registered Users" count.
    10. **Observe:** Note the updated "New Registrations (Daily)" count.
    11. **Wait:** Wait until after 24 hours.
    12. **Navigate:** Refresh the "Users Metrics" dashboard or reporting page.
    13. **Observe:** Note the updated "New Registrations (Daily)" count.

*   **Expected Result:**

    *   **Step 5:** The "Total Registered Users" count is accurately displayed.
    *   **Step 6:** The "New Registrations (Daily)" count is accurately displayed as 0.
    *   **Step 9:** The "Total Registered Users" count increments by X. (e.g., if X=3, and the original count was 100, the new count should be 103).
    *   **Step 10:** The "New Registrations (Daily)" count increases by X (e.g., if X=3, the new count should be 3).
    *   **Step 13:** The "New Registrations (Daily)" count is updated to 0.

*   **Priority:** High

**Test Case 2: Verify Editing Metric Description Functionality**

*   **Title:** Verify Metric Description Can Be Edited Successfully

*   **Description:** This test case verifies that an administrator can successfully edit the description of a user metric (e.g., the description associated with "Total Registered Users"). This includes verifying the edit functionality, data persistence, and display of the updated description.

*   **Steps:**

    1.  **Pre-condition:** User needs to be logged in with Admin Access.
    2.  **Navigate:** Log in to the application as an administrator.
    3.  **Navigate:** Access the "Users Metrics" dashboard or reporting page.
    4.  **Locate:** Identify the "Total Registered Users" metric (or another metric with an editable description).
    5.  **Observe:** Note the current description of the metric.
    6.  **Action:** Click the "Edit Description" (or similar) button/link associated with the metric.
    7.  **Action:** Enter a new description for the metric (e.g., "This metric tracks the total number of users who have registered in the system since its launch.").
    8.  **Action:** Save the changes by clicking the "Save" (or similar) button.
    9.  **Observe:** Verify that the new description is displayed correctly on the "Users Metrics" dashboard.
    10. **Navigate:** Log out and log back in as the same administrator.
    11. **Navigate:** Access the "Users Metrics" dashboard or reporting page.
    12. **Observe:** Verify that the updated description is still displayed correctly.

*   **Expected Result:**

    *   **Step 5:** The initial description is correctly displayed.
    *   **Step 9:** The "Users Metrics" dashboard displays the new description entered in Step 7.
    *   **Step 12:** The "Users Metrics" dashboard displays the new description entered in Step 7, confirming that the change was saved and persisted.

*   **Priority:** High
