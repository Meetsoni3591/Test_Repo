**Test Case 1: Admin User Creation & Login**

*   **Title:** Verify Admin User Creation and Login Functionality

*   **Description:**  This test case verifies that an administrator can successfully create a new admin user account, and that the new admin user can successfully log in to the system with the created credentials.

*   **Steps:**

    1.  **Pre-Condition:** The user must have Admin privileges or have proper access to the admin dashboard.
    2.  Navigate to the "Admin Users" or "User Management" section of the admin dashboard.
    3.  Click on the "Add New User" or "Create User" button.
    4.  Fill out all required fields in the user creation form, including:
        *   Username
        *   Password (and Password Confirmation)
        *   Email Address
        *   First Name
        *   Last Name
        *   Role (Select "Administrator")
    5.  Submit the form.
    6.  Log out of the current admin account.
    7.  Using the newly created admin user's credentials (username and password), attempt to log in.

*   **Expected Result:**

    1.  Upon submitting the user creation form, a success message should be displayed, confirming the user account has been created.
    2.  The new user should be successfully created and listed in the user management table.
    3.  Upon logging in with the new admin user's credentials, the user should be redirected to the admin dashboard or the appropriate landing page for admin users.
    4.  No error messages should be displayed during the login process.

*   **Priority:** High

**Test Case 2: Admin User Deactivation**

*   **Title:** Verify Admin User Deactivation Functionality

*   **Description:**  This test case verifies that an administrator can successfully deactivate an existing admin user account, preventing them from logging in.

*   **Steps:**

    1.  **Pre-Condition:** The user must have Admin privileges or have proper access to the admin dashboard and user management.
    2.  Navigate to the "Admin Users" or "User Management" section of the admin dashboard.
    3.  Locate the admin user account to be deactivated. (Ensure this is NOT the account currently logged in!)
    4.  Select the "Deactivate" or "Disable" option associated with the user account. This might be a button, a dropdown menu option, or a checkbox.
    5.  Confirm the deactivation in the confirmation dialog box (if present).
    6.  Attempt to log in with the deactivated user's credentials (username and password).

*   **Expected Result:**

    1.  The user account should be marked as "Inactive" or "Deactivated" in the user management list. The UI should visually indicate the deactivated status (e.g., greyed out row, different status icon).
    2.  When attempting to log in with the deactivated user's credentials, the system should display an error message indicating that the account is disabled or inactive.  The user should not be able to access the system.
    3.  No unexpected errors should occur.
    4.  It should not be possible for the deactivated user to circumvent the deactivation process and gain access to the system.

*   **Priority:** High
