**Test Case 1:  Title Tag Optimization Verification**

*   **Description:**  This test case verifies that title tags are present, properly formatted, and include relevant keywords for key landing pages, which are assumed to be the homepage, a product category page, and a specific product page.  This checks that the title tags are aligned with SEO best practices for the intended search queries. This assumes we are prioritizing important pages on the website, and have selected appropriate keywords (this should be confirmed with the SEO Specialist).

*   **Steps:**

    1.  **Homepage:** Navigate to the homepage (e.g., `https://www.example.com`).
    2.  **View Source:**  Right-click on the page and select "View Page Source" (or equivalent in your browser).
    3.  **Locate Title Tag:**  Search for the `<title>` tag within the source code.
    4.  **Record Title Tag Content:**  Note the exact text contained within the `<title>` tag.
    5.  **Product Category Page:** Navigate to a representative product category page (e.g., `https://www.example.com/category/example-category`).
    6.  **View Source:** Right-click on the page and select "View Page Source" (or equivalent in your browser).
    7.  **Locate Title Tag:**  Search for the `<title>` tag within the source code.
    8.  **Record Title Tag Content:** Note the exact text contained within the `<title>` tag.
    9.  **Specific Product Page:** Navigate to a specific product page (e.g., `https://www.example.com/product/example-product`).
    10. **View Source:** Right-click on the page and select "View Page Source" (or equivalent in your browser).
    11. **Locate Title Tag:**  Search for the `<title>` tag within the source code.
    12. **Record Title Tag Content:** Note the exact text contained within the `<title>` tag.
    13. **Analyze Title Tags:** Review the recorded title tags for the following:
        *   **Presence:**  Was a `<title>` tag found on each page?
        *   **Length:**  Is the title tag length within the recommended limit (typically 50-60 characters)? Use a character count tool.
        *   **Keyword Inclusion:** Does the title tag include relevant keywords for that specific page, assuming these have been identified previously.
        *   **Relevance:** Does the title tag accurately reflect the content of the page?
        *   **Uniqueness:** Are the title tags unique for each tested page?
    14. **Compare to Expected Values**:  Compare your findings to the list of expected values (see below)

*   **Expected Result:**

    *   **Homepage:** A `<title>` tag is present. The content is approximately 50-60 characters and contains the brand name and a relevant keyword phrase like "Official Website" or "Online Store". Example:  `<title>Example Brand - Official Website</title>`
    *   **Product Category Page:** A `<title>` tag is present. The content is approximately 50-60 characters and contains the category name and the brand name. Example: `<title>Example Category - Example Brand</title>`
    *   **Specific Product Page:** A `<title>` tag is present. The content is approximately 50-60 characters and contains the product name and the brand name. Example: `<title>Example Product - Example Brand</title>`
    *   Title tags should be unique across the three pages.
    *   All title tags should be concise, compelling, and relevant to the page content.

*   **Priority:** High

**Test Case 2: Meta Description Optimization Verification**

*   **Description:** This test case verifies that meta descriptions are present, properly formatted, and include relevant keywords for key landing pages, which are assumed to be the homepage, a product category page, and a specific product page. This checks that the meta descriptions are aligned with SEO best practices to encourage clicks from search engine results pages (SERPs).

*   **Steps:**

    1.  **Homepage:** Navigate to the homepage (e.g., `https://www.example.com`).
    2.  **View Source:**  Right-click on the page and select "View Page Source" (or equivalent in your browser).
    3.  **Locate Meta Description Tag:**  Search for the `<meta name="description" content="...">` tag within the source code.
    4.  **Record Meta Description Tag Content:**  Note the exact text contained within the `content` attribute of the meta description tag.
    5.  **Product Category Page:** Navigate to a representative product category page (e.g., `https://www.example.com/category/example-category`).
    6.  **View Source:** Right-click on the page and select "View Page Source" (or equivalent in your browser).
    7.  **Locate Meta Description Tag:**  Search for the `<meta name="description" content="...">` tag within the source code.
    8.  **Record Meta Description Tag Content:** Note the exact text contained within the `content` attribute of the meta description tag.
    9.  **Specific Product Page:** Navigate to a specific product page (e.g., `https://www.example.com/product/example-product`).
    10. **View Source:** Right-click on the page and select "View Page Source" (or equivalent in your browser).
    11. **Locate Meta Description Tag:**  Search for the `<meta name="description" content="...">` tag within the source code.
    12. **Record Meta Description Tag Content:** Note the exact text contained within the `content` attribute of the meta description tag.
    13. **Analyze Meta Descriptions:** Review the recorded meta descriptions for the following:
        *   **Presence:**  Was a meta description tag found on each page?
        *   **Length:**  Is the meta description length within the recommended limit (typically 150-160 characters)? Use a character count tool.
        *   **Keyword Inclusion:** Does the meta description include relevant keywords for that specific page?
        *   **Relevance:** Does the meta description accurately summarize the content of the page and entice users to click?
        *   **Uniqueness:** Are the meta descriptions unique for each tested page?
    14. **Compare to Expected Values**: Compare your findings to the list of expected values (see below)

*   **Expected Result:**

    *   **Homepage:** A `<meta name="description" content="...">` tag is present. The content is approximately 150-160 characters and provides a concise overview of the website, highlighting key offerings and the brand's value proposition. Example: `<meta name="description" content="Example Brand offers high-quality products and services. Shop now and experience the difference!">`
    *   **Product Category Page:** A `<meta name="description" content="...">` tag is present. The content is approximately 150-160 characters and describes the products available in the category, highlighting key features and benefits. Example: `<meta name="description" content="Browse our wide selection of Example Category products. Find the perfect solution for your needs today!">`
    *   **Specific Product Page:** A `<meta name="description" content="...">` tag is present. The content is approximately 150-160 characters and describes the specific product, highlighting its features, benefits, and unique selling points. Example: `<meta name="description" content="The Example Product is a must-have! [Insert Product highlights and description here]">`
    *   Meta descriptions should be unique across the three pages.
    *   All meta descriptions should be compelling, action-oriented, and relevant to the page content.

*   **Priority:** High
**Important Considerations and Next Steps:**

*   **Collaboration with SEO Specialist:** These test cases are based on assumptions.  It's crucial to work closely with an SEO specialist to determine the *actual* SEO optimizations that have been implemented and the specific keywords being targeted.
*   **Keyword Research:** If keyword research hasn't been completed, it should be a top priority.  The "Expected Result" sections of these test cases need to be populated with specific keywords.
*   **Content Management System (CMS):** The method for updating title tags and meta descriptions often depends on the CMS being used (e.g., WordPress, Drupal, custom CMS).  Ensure the relevant CMS functionality is working as expected.
*   **Robots.txt:** You might want to test that the `robots.txt` file is configured correctly to allow or disallow crawling of specific pages.
*   **Sitemap:** Verify that an XML sitemap is present and submitted to search engines.
*   **Mobile-Friendliness:** SEO now heavily weights mobile-friendliness. Separate test cases should address this aspect.
*   **Page Speed:** Page load speed is an SEO factor.  Consider using tools like Google PageSpeed Insights to measure performance.
*   **Schema Markup:** Verify the presence and validity of schema markup for relevant content types (products, articles, etc.).

These two test cases provide a solid starting point for testing SEO optimizations related to title tags and meta descriptions. By working with the SEO team and refining these tests based on specific requirements, you can ensure the website is properly optimized for search engines.
