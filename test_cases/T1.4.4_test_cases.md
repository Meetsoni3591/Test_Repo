**Test Case 1: Basic Application Deployment and Accessibility Across Hosting Platforms**

*   **Title:** Application Deployment and Accessibility on AWS, Azure, and Heroku
*   **Description:** This test case verifies the ability to successfully deploy a basic, pre-built application (e.g., a simple "Hello World" application) to AWS, Azure, and Heroku, and that the application is accessible and returns the expected output.  This test focuses on core deployment functionality and network accessibility.
*   **Steps:**

    1.  **Preparation:**
        *   Create a simple "Hello World" application (e.g., in Python, Node.js, or Java) that returns "Hello, World!" when accessed via HTTP.
        *   Create accounts on AWS, Azure, and Heroku (if not already available).
        *   Gather necessary credentials for each platform (e.g., AWS Access Key ID/Secret Access Key, Azure Service Principal, Heroku API Key).
    2.  **AWS Deployment:**
        *   Using AWS Elastic Beanstalk or a similar service, deploy the "Hello World" application. Configure necessary security groups to allow HTTP traffic (port 80).
        *   Obtain the public URL of the deployed application.
    3.  **Azure Deployment:**
        *   Using Azure App Service or a similar service, deploy the "Hello World" application.
        *   Obtain the public URL of the deployed application.
    4.  **Heroku Deployment:**
        *   Using the Heroku CLI or web interface, deploy the "Hello World" application.
        *   Obtain the public URL of the deployed application.
    5.  **Verification:**
        *   For each platform (AWS, Azure, Heroku), access the public URL of the deployed application using a web browser or a command-line tool like `curl` or `wget`.
        *   Verify that the response body contains "Hello, World!".
        *   Verify the HTTP Status code is 200 OK.
*   **Expected Result:**
    *   The "Hello World" application should be successfully deployed to AWS, Azure, and Heroku.
    *   Accessing the public URL of each deployed application should return an HTTP 200 OK response.
    *   The response body for each application should contain the exact string "Hello, World!".

*   **Priority:** High
