**Test Case 1: Verify Database Connection Configuration Steps in Deployment Guide**

*   **Title:** Verify Database Connection Configuration Steps in Deployment Guide
*   **Description:** This test case verifies that the steps outlined in the deployment guide for configuring a database connection (specifically to the `Production_DB` server) are accurate, complete, and result in a successful connection.  This test is performed on a fresh installation.  The guide should accurately describe the server name, database name, user, password, and any specific connection string parameters.
*   **Steps:**

    1.  Access the latest version of the Deployment Guide document (specify the location, e.g., Confluence page, shared drive path).
    2.  Locate the section titled "Database Configuration" and then the subsection "Production Database (Production_DB)".
    3.  On a clean system (VM or environment without any prior installation), begin the deployment process.
    4.  Follow the instructions in the deployment guide to configure the database connection to the `Production_DB` server.  Specifically, provide the database name, server name, username, password as instructed.
    5.  After completing the configuration steps outlined in the guide, attempt to establish a connection to the `Production_DB` database.
    6.  Confirm that the application (after deployment) can successfully perform a basic database operation, such as retrieving a record or inserting a new record. The exact verification will depend on the application's functionality (e.g., "Retrieve the number of items in the 'Products' table").
*   **Expected Result:**

    *   The database connection is successfully established.
    *   The application is able to perform database operations without errors.
    *   All steps outlined in the Deployment Guide were necessary and sufficient to configure the database connection.
    *   The database interaction is functioning (as defined in step 6 - e.g. number of items in the 'Products' table is displayed correctly).
*   **Priority:** High

**Test Case 2: Validate Production Database Credentials Against Password Policy**

*   **Title:** Validate Production Database Credentials Against Password Policy
*   **Description:** This test case verifies that the credentials (username and password) provided in the deployment guide for accessing the production database adhere to the company's password policy, specifically regarding minimum length, complexity (uppercase, lowercase, numbers, special characters), and password expiration. This will use the same Production_DB credentials tested in TC1.
*   **Steps:**

    1.  Obtain the username and password for the `Production_DB` database from the deployment guide (specify the location).
    2.  Note the date that the credentials were provided in the deployment guide.
    3.  Consult the company's password policy document (specify location, e.g., Confluence page).
    4.  Verify the following conditions against the current password policy:
        *   **Minimum Length:** Is the password at least the minimum required length (e.g., 12 characters)?
        *   **Complexity:** Does the password contain at least one uppercase letter, one lowercase letter, one number, and one special character?
        *   **Password Expiration:** Is the password within the allowed lifetime from the creation/last change date?
    5.  Attempt to change the database password using the credentials from the deployment guide (as the current password) to a password that intentionally violates the password policy (e.g., too short, all lowercase).
*   **Expected Result:**

    *   The password from the deployment guide meets all the criteria defined in the company's password policy (minimum length, complexity, non-expired).
    *   The password change attempt to a password violating the policy fails with a clear error message indicating the reason for the failure (e.g., "Password must be at least 12 characters long.").
*   **Priority:** High
