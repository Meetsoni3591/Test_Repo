# Test Cases for T2.1.2 - Contact Information Restaurant

Okay, here are two detailed test cases based on the provided task "Contact Information Restaurant," covering different aspects of adding contact details for Venue Managers:

**Test Case 1: Valid Contact Information Submission**

*   **Title:** Verify Successful Addition of Venue Manager Contact Details with Valid Input

*   **Description:** This test case verifies that the system successfully adds the contact details for a Venue Manager when all required fields are populated with valid data, and optional fields, if used, also contain valid data.

*   **Steps:**

    1.  Log in to the application as an administrator or user with the necessary permissions to manage Venue Manager contact information.
    2.  Navigate to the "Venue Manager Contact Information" or relevant management page.
    3.  Click on the "Add New Contact" or similar button to initiate the contact creation process.
    4.  Enter valid data into all mandatory fields:
        *   **First Name:** "John"
        *   **Last Name:** "Doe"
        *   **Email:** "john.doe@example.com" (valid email format)
        *   **Phone Number:** "555-123-4567" (valid phone number format)
    5.  Optionally, enter data into available optional fields:
        *   **Job Title:** "Area Manager"
        *   **Secondary Phone Number:** "555-987-6543"
        *   **Notes:** "Preferred contact person for scheduling."
    6.  Click the "Save" or "Submit" button to save the contact information.
    7.  Upon successful saving, confirm the appearance of a success message.

*   **Expected Result:**

    1.  The system should successfully add the new contact information without any errors.
    2.  A success message (e.g., "Contact information saved successfully") should be displayed to the user.
    3.  The newly added contact information (including all entered fields) should be visible in the list of Venue Manager contacts on the relevant management page.
    4.  The contact information (First name, Last name, Email, Phone number) should be stored in the database correctly.

*   **Priority:** High

**Test Case 2: Invalid Email Format**

*   **Title:** Verify Error Handling When Adding Venue Manager Contact Details with Invalid Email Format

*   **Description:** This test case verifies that the system correctly identifies and handles invalid email formats when adding contact details for a Venue Manager, preventing the submission of incorrect data.

*   **Steps:**

    1.  Log in to the application as an administrator or user with the necessary permissions to manage Venue Manager contact information.
    2.  Navigate to the "Venue Manager Contact Information" or relevant management page.
    3.  Click on the "Add New Contact" or similar button to initiate the contact creation process.
    4.  Enter the following data:
        *   **First Name:** "Jane"
        *   **Last Name:** "Smith"
        *   **Email:** "jane.smith@example" (invalid email format - missing .com)
        *   **Phone Number:** "555-444-3333"
    5.  Click the "Save" or "Submit" button to save the contact information.

*   **Expected Result:**

    1.  The system should *not* save the contact information.
    2.  An appropriate error message should be displayed to the user, clearly indicating that the email format is invalid (e.g., "Please enter a valid email address," or "Invalid email format.").
    3.  The error message should be displayed adjacent to the email input field or in a prominent location on the form.
    4.  The error message should persist until the user corrects the email address.
    5. The information should not be saved in the database.

*   **Priority:** High
