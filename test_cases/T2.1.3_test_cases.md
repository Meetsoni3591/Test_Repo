# Test Cases for T2.1.3 - Business Agreement Details Restaurant

Okay, here are two detailed test cases covering the functionality of adding commission structures and discount rates to a Business Agreement Details page for a restaurant.

**Test Case 1: Adding a Tiered Commission Structure**

*   **Title:** Verify Successful Addition of Tiered Commission Structure to a Business Agreement

*   **Description:** This test case validates the ability to successfully add and save a tiered commission structure to a Business Agreement for a restaurant. Tiered commission structures allow for varying commission rates based on order value.

*   **Steps:**

    1.  Navigate to the Business Agreements section in the application.
    2.  Locate and select the specific Business Agreement for the target restaurant.
    3.  Navigate to the "Commission Structure" tab/section.
    4.  Click the "Add Commission Structure" or similar button.
    5.  Select "Tiered Commission" as the type of commission structure.
    6.  Enter the following tier details:
        *   **Tier 1:**
            *   Order Value From: 0
            *   Order Value To: 50
            *   Commission Rate: 10%
        *   **Tier 2:**
            *   Order Value From: 50.01
            *   Order Value To: 100
            *   Commission Rate: 12%
        *   **Tier 3:**
            *   Order Value From: 100.01
            *   Order Value To: 200
            *   Commission Rate: 15%
    7.  Set the effective date of the tiered commission structure (e.g., current date).
    8.  (Optional) Add notes to the Commission Structure for documentation.
    9.  Click the "Save" button.

*   **Expected Result:**

    1.  The tiered commission structure is successfully saved and displayed in the "Commission Structure" table/section.
    2.  The saved tiers (Order Value From, Order Value To, and Commission Rate) are displayed accurately.
    3.  The effective date of the commission structure is correctly displayed.
    4.  A success message (e.g., "Commission Structure saved successfully.") is displayed to the user.
    5.  The database record for the commission structure is updated with the entered values and linked to the correct Business Agreement.

*   **Priority:** High

**Test Case 2: Adding and Validating Discount Rate Functionality**

*   **Title:** Verify Discount Rate Addition and Application to a Business Agreement

*   **Description:** This test case validates the ability to add, save, and apply discount rates to a Business Agreement for a restaurant. It also confirms that the discounts are calculated correctly when applied to orders.

*   **Steps:**

    1.  Navigate to the Business Agreements section in the application.
    2.  Locate and select the specific Business Agreement for the target restaurant.
    3.  Navigate to the "Discount Rates" tab/section.
    4.  Click the "Add Discount Rate" or similar button.
    5.  Enter the following details:
        *   Discount Name: "New Customer Discount"
        *   Discount Type: Percentage
        *   Discount Value: 5%
        *   Applicable to: Total Order Value
        *   Start Date: Current Date
        *   End Date: 1 Month from Current Date
    6.  (Optional) Add notes to the Discount Rate for documentation.
    7.  Click the "Save" button.
    8.  Create a new order for the restaurant linked to the Business Agreement.
    9.  Add items to the order that total $100 before discounts.
    10. Apply the "New Customer Discount" to the order.
    11. Verify the discounted order total.

*   **Expected Result:**

    1.  The discount rate is successfully saved and displayed in the "Discount Rates" table/section.
    2.  All entered details (Discount Name, Discount Type, Discount Value, Applicable to, Start Date, End Date) are displayed correctly.
    3.  A success message (e.g., "Discount Rate saved successfully.") is displayed to the user.
    4.  The database record for the discount rate is updated with the entered values and linked to the correct Business Agreement.
    5.  When the "New Customer Discount" is applied to a $100 order, the discounted total is $95.
    6.  The discount applied should be recorded in the order details.

*   **Priority:** High
