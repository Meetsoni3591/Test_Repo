# Test Cases for T2.2.1 - Basic Details Clubbing

Okay, here are two detailed test cases based on the "Basic Details Clubbing" task, covering different aspects of the functionality and considering potential edge cases:

**Test Case 1: Successful Creation of Venue with All Basic Details**

*   **Title:** Create Venue with All Required Basic Details
*   **Description:** This test case verifies that a user can successfully create a new venue (bar, club, lounge) by providing all the required basic details: Name, Address, Phone Number, Logo, and Venue Type.
*   **Steps:**

    1.  Navigate to the venue creation page/section.
    2.  Enter a valid venue name in the "Name" field (e.g., "The Electric Owl").
    3.  Enter a valid street address in the "Address" field (e.g., "123 Main Street").
    4.  Enter a valid phone number in the "Phone Number" field (e.g., "555-123-4567").
    5.  Click the "Upload Logo" button and select a valid image file from local machine/storage.  (Ensure the image file adheres to any size or format requirements - note the file type and size used. e.g. "logo.jpg", 200KB)
    6.  Select the Venue Type "Bar" from the "Venue Type" dropdown menu.
    7.  Click the "Save" or "Create" button.
*   **Expected Result:**

    1.  The venue should be successfully created.
    2.  A success message should be displayed to the user (e.g., "Venue created successfully!").
    3.  The user should be redirected to the venue details page or a venue listing page where the newly created venue is visible.
    4.  On the venue details page, the "Name" field should display "The Electric Owl".
    5.  On the venue details page, the "Address" field should display "123 Main Street".
    6.  On the venue details page, the "Phone Number" field should display "555-123-4567".
    7.  On the venue details page, the correct logo image should be displayed.
    8.  On the venue details page, the "Venue Type" field should display "Bar".
*   **Priority:** High

**Test Case 2: Error Handling for Missing Required Basic Details**

*   **Title:** Validation of Required Fields During Venue Creation
*   **Description:** This test case verifies that the system correctly validates the required fields (Name, Address, Phone Number, Logo, Venue Type) during venue creation and displays appropriate error messages to the user when any of these fields are missing or invalid.
*   **Steps:**

    1.  Navigate to the venue creation page/section.
    2.  Leave the "Name" field blank.
    3.  Enter a valid address in the "Address" field (e.g., "456 Oak Avenue").
    4.  Enter a valid phone number in the "Phone Number" field (e.g., "555-987-6543").
    5.  Click the "Upload Logo" button and select a valid image file from local machine/storage.
    6.  Select the Venue Type "Club" from the "Venue Type" dropdown menu.
    7.  Click the "Save" or "Create" button.
    8.  Repeat steps 1-7, but this time leave a *different* field blank each time. Specifically, test leaving the Address, Phone Number, Logo, and Venue Type fields blank *separately*.  Note that you may have to re-enter data from other fields to ensure the "Save" button is enabled.
    9. Leave the "Address" field as an invalid value (e.g. "<script>").
    10. Leave the "Phone Number" field as an invalid value (e.g. "abc").
    11. Select a Logo with an invalid file type (e.g. ".txt").

*   **Expected Result:**

    1.  When the "Name" field is left blank, an error message should be displayed near the "Name" field indicating that it is required (e.g., "Name is required").  The venue should *not* be created.
    2.  When the "Address" field is left blank, an error message should be displayed near the "Address" field indicating that it is required (e.g., "Address is required"). The venue should *not* be created.
    3.  When the "Phone Number" field is left blank, an error message should be displayed near the "Phone Number" field indicating that it is required (e.g., "Phone Number is required"). The venue should *not* be created.
    4.  When the "Logo" field is left blank, an error message should be displayed near the "Logo" field indicating that it is required (e.g., "Logo is required").  The venue should *not* be created.
    5.  When the "Venue Type" is not selected, an error message should be displayed near the "Venue Type" field indicating that it is required (e.g., "Venue Type is required"). The venue should *not* be created.
    6.  When the "Address" field contains an invalid value, an error message should be displayed near the "Address" field indicating it is invalid (e.g. "Address is invalid"). The venue should *not* be created.
    7.  When the "Phone Number" field contains an invalid value, an error message should be displayed near the "Phone Number" field indicating it is invalid (e.g. "Phone Number is invalid"). The venue should *not* be created.
    8.  When the "Logo" field has an invalid file type selected, an error message should be displayed near the "Logo" field indicating it is invalid (e.g. "Logo must be a valid image type"). The venue should *not* be created.
    9.  The "Save" or "Create" button should be disabled or should trigger the error messages when clicked.
*   **Priority:** High
