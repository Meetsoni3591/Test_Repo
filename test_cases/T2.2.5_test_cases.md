# Test Cases for T2.2.5 - Venue Profile Clubbing

Okay, I can provide two detailed test cases for the "Venue Profile Clubbing" task, covering different aspects of the functionality.

**Test Case 1: Positive - Create a Valid Club Venue Profile**

*   **Title:** Verify Successful Creation of a Club Venue Profile with Valid Data
*   **Description:** This test case verifies that a user can successfully create a new club venue profile by providing valid data for all required and optional fields as specified in the task description.
*   **Steps:**

    1.  Navigate to the Venue Management/Administration section of the application.
    2.  Click on "Add Venue" or a similar button to initiate the creation of a new venue profile.
    3.  Select "Club" as the Venue Type.
    4.  Enter a valid name for the club in the "Name of Club" field (e.g., "The Groove").
    5.  Upload a valid image file for the club logo using the "Logo" upload control (e.g., .jpg, .png within acceptable size limits).
    6.  Select a valid "Type" from the available options (e.g., Nightclub, Dance Club).
    7.  Enter a valid numerical value for "Commission" (e.g., 10).
    8.  Set the "Guestlist" option to "Yes."
    9.  Select "Yes" for "Indoors" and "Outdoors" if applicable to the venue.  If not, select "No".
    10. Select "Yes" or "No" for "Bar" based on venue characteristics.
    11. Select "Yes" or "No" for "Special Events" based on venue characteristics.
    12. Enter a valid time (e.g., 21:00) for "Guestlist Open Time."
    13. Enter a valid time (e.g., 23:00) for "Guestlist Closing Time."
    14. Enter a valid time (e.g., 22:00) for "Venue Opening Time."
    15. Enter a valid time (e.g., 04:00) for "Venue Closing Time."
    16. Enter a valid numerical value for "Max party size for booking" (e.g., 10).
    17. Enter relevant "Discount Details" (e.g., "20% off drinks before 11 PM").
    18. Enter a descriptive "Description/Caption" for the club (e.g., "The Groove is the hottest nightclub in town, featuring top DJs and a vibrant atmosphere.").
    19. Click the "Save" or "Create" button to submit the venue profile.

*   **Expected Result:**

    1.  The venue profile is created successfully.
    2.  A success message (e.g., "Venue created successfully") is displayed to the user.
    3.  The newly created venue profile is displayed in the Venue Management list/table with the correct information.
    4.  The uploaded logo is displayed correctly in the venue profile and on any relevant listing pages.
    5.  All entered data (Name, Type, Commission, Guestlist settings, times, party size, discounts, description) is saved correctly and displayed accurately in the venue profile.
*   **Priority:** High

**Test Case 2: Negative - Attempt to Create a Club Venue Profile with Invalid Data**

*   **Title:** Verify Error Handling for Invalid Input Data During Club Venue Profile Creation
*   **Description:** This test case verifies that the application correctly handles invalid input data provided during the creation of a club venue profile and displays appropriate error messages to the user.  It covers various invalid data scenarios.
*   **Steps:**

    1.  Navigate to the Venue Management/Administration section of the application.
    2.  Click on "Add Venue" or a similar button to initiate the creation of a new venue profile.
    3.  Select "Club" as the Venue Type.
    4.  **Scenario 1: Missing Required Fields:** Leave the "Name of Club" field blank. Enter valid data for other fields. Click "Save."
    5.  **Scenario 2: Invalid Logo File:** Attempt to upload a file that is not an image (e.g., a .txt file) or an image file that is too large.  Enter valid data for other fields. Click "Save."
    6.  **Scenario 3: Invalid Commission Value:** Enter a non-numeric value (e.g., "abc") or a negative value (e.g., -5) in the "Commission" field. Enter valid data for other fields. Click "Save."
    7.  **Scenario 4: Invalid Time Format:** Enter an invalid time format (e.g., "25:00" or "10:75") in "Guestlist Open Time," "Guestlist Closing Time," "Venue Opening Time," or "Venue Closing Time." Enter valid data for other fields. Click "Save."
    8.  **Scenario 5: Guestlist closing time before opening time:** Enter the guestlist opening time to be after the guestlist closing time.
    9.  **Scenario 6: Max Party Size Non-Numeric:** Enter a non-numeric value (e.g. "Ten") for max party size
    10. **Scenario 7: Exceed Maximum Character length for Description:** Enter a description with an amount of characters over the allowed limit.

*   **Expected Result:**

    1.  For each scenario, the application **prevents** the venue profile from being created.
    2.  For each scenario, a clear and informative error message is displayed to the user, indicating the specific field(s) with invalid data and the reason for the error (e.g., "Name of Club is required," "Invalid file type for logo. Please upload a .jpg or .png file," "Commission must be a valid number," "Invalid time format. Please use HH:MM format," "Guestlist closing time must be after Guestlist opening time", "Max party size must be numeric").
    3.  The error messages should be displayed near the corresponding fields that contain the invalid data or in a consolidated error summary at the top of the form.
    4.  The application should preserve the valid data entered by the user in other fields, so the user does not have to re-enter all the information.
*   **Priority:** High
