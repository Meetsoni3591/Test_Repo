# Test Cases for T2.2 - Venue Profiles Clubbing

Okay, here are two detailed test cases for creating/updating a venue profile for clubbing, suitable for a senior QA engineer:

**Test Case 1: Creation of a New Venue Profile for Clubbing with Valid Data**

*   **Title:** Create New Venue Profile - Clubbing - Valid Data
*   **Description:** This test case verifies the successful creation of a new venue profile specifically configured for a clubbing venue using all valid data inputs.
*   **Steps:**

    1.  Navigate to the Venue Management section within the application.
    2.  Click on the "Create New Venue" button.
    3.  Select "Clubbing" as the Venue Type.
    4.  In the "Venue Name" field, enter a unique and descriptive name (e.g., "The Galactic Groove").
    5.  In the "Address" field, enter a valid street address (e.g., "123 Main Street").
    6.  In the "City" field, enter a valid city (e.g., "Anytown").
    7.  In the "State" field, select a valid state from the dropdown (e.g., "CA").
    8.  In the "Zip Code" field, enter a valid zip code (e.g., "90210").
    9.  In the "Contact Phone" field, enter a valid phone number (e.g., "555-123-4567").
    10. In the "Contact Email" field, enter a valid email address (e.g., "info@galacticgroove.com").
    11. In the "Description" field, enter a detailed description of the club (e.g., "The hottest new club in Anytown, featuring top DJs and state-of-the-art sound and lighting.").
    12. In the "Operating Hours" section, define valid operating hours for each day of the week (e.g., Friday and Saturday 10:00 PM to 3:00 AM).
    13. Upload a relevant image/logo for the venue, ensuring it meets the specified file type and size requirements.
    14. In the "Music Genre" section, select several genres appropriate for a clubbing venue (e.g., "Electronic", "House", "Techno", "Hip-Hop").
    15. In the "Amenities" section, select appropriate amenities from the list (e.g., "Full Bar", "Dance Floor", "VIP Area", "Bottle Service").
    16. Click the "Save" or "Create" button.
    17. Verify that venue appears on the venue list.

*   **Expected Result:**

    1.  The new venue profile is successfully created and saved in the system.
    2.  A confirmation message is displayed to the user indicating successful creation (e.g., "Venue 'The Galactic Groove' created successfully.").
    3.  The venue profile details are displayed accurately on the venue management page.
    4.  All entered data is correctly stored in the database.
    5.  The uploaded image/logo is displayed correctly in the venue profile.

*   **Priority:** High

**Test Case 2: Update Existing Venue Profile - Clubbing - Verify Data Integrity and Functionality**

*   **Title:** Update Existing Venue Profile - Clubbing - Verify Data Integrity and Functionality
*   **Description:** This test case verifies that an existing clubbing venue profile can be successfully updated, retaining existing data where appropriate, and validates the functionality of update operations.
*   **Steps:**

    1.  Navigate to the Venue Management section within the application.
    2.  Locate an existing venue profile that is designated as "Clubbing" (e.g., "The Galactic Groove" - created from Test Case 1, or a pre-existing clubbing venue).
    3.  Click on the "Edit" or "Update" button associated with the selected venue profile.
    4.  Change the "Venue Name" to a new name (e.g., "The Cosmic Club").
    5.  Change the "Operating Hours" for a specific day (e.g., update Friday hours to 9:00 PM - 4:00 AM).
    6.  Add a new music genre to the "Music Genre" list (e.g., "Trance").
    7.  Remove an existing amenity from the "Amenities" list (e.g., remove "Bottle Service").
    8.  Update the venue "Description" field with additional information.
    9.  Replace the existing image/logo with a new image/logo. Ensure it meets specified file type and size.
    10. Click the "Save" or "Update" button.

*   **Expected Result:**

    1.  The existing venue profile is successfully updated with the new information.
    2.  A confirmation message is displayed to the user indicating successful update (e.g., "Venue 'The Cosmic Club' updated successfully.").
    3.  The venue profile details are displayed accurately on the venue management page reflecting the changes made.
    4.  All updated data is correctly stored in the database, and previous data is overwritten correctly.
    5.  The "Venue Name" in venue list reflects the new name of the venue.
    6.  The updated image/logo is displayed correctly in the venue profile, and the old image/logo is removed from the system (if appropriate storage strategy is in place).
    7. The data stored in the database matches the changes performed in steps 4 through 9.

*   **Priority:** High
