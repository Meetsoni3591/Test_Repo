**Test Case 1: Guestlist Sign-Up Tracking and Check-In Accuracy**

*   **Title:** Verify Guestlist Sign-Up Count and Check-In Accuracy
*   **Description:** This test case verifies that the system accurately tracks the number of guestlist sign-ups for an event and correctly records and reflects attendance (check-ins) based on the guestlist.  It aims to ensure the integrity of the sign-up and attendance data.
*   **Steps:**

    1.  **Pre-condition**: An event "Tech Conference 2024" exists in the system with a defined capacity and guestlist feature enabled.
    2.  Log in to the system as an Event Manager with appropriate permissions.
    3.  Navigate to the "Tech Conference 2024" event details page.
    4.  Note the initial "Guestlist Sign-Ups" count (should be 0 if a new event).
    5.  Generate 10 unique guestlist sign-up links (through the system or manually via API call).
    6.  Distribute these 10 links via Email/SMS.
    7.  Using different browsers or devices, access each of the 10 generated links and complete the guestlist sign-up process, providing unique valid contact information (name, email) for each.
    8.  Refresh the "Tech Conference 2024" event details page.
    9.  Verify the "Guestlist Sign-Ups" count.
    10. Navigate to event dashboard to check in attendees.
    11. Manually check-in 6 of the signed-up guests using the check-in functionality (search by name or QR code scanning if applicable).
    12. Refresh the "Tech Conference 2024" event details page.
    13.  Verify the "Check-Ins / Attendance" count.
    14. Simulate an API call to add 3 new attendees to guestlist.
    15. Verify Guestlist sign-up is updated with the API call.
*   **Expected Result:**

    1.  Step 4: The initial "Guestlist Sign-Ups" count is 0.
    2.  Step 9: The "Guestlist Sign-Ups" count should accurately reflect 10 new sign-ups.
    3.  Step 13: The "Check-Ins / Attendance" count should accurately reflect 6 attendees.
    4.  Step 15: The "Guestlist Sign-Ups" count should accurately reflect 13 attendees.
*   **Priority:** High

**Test Case 2: Discount Usage and Revenue Generation Calculation**

*   **Title:** Verify Discount Usage Tracking and Revenue Calculation
*   **Description:** This test case verifies the system's ability to accurately track the usage of discount codes applied during event registration/ticket purchase and ensures the correct calculation of revenue generated from ticket sales after discounts are applied. This test also check revenue generated after applying taxes.
*   **Steps:**

    1.  **Pre-condition:** An event "Gaming Convention" exists in the system. Tickets for the event are priced at $50 each.  A discount code "EARLYBIRD" exists, offering a 20% discount. Taxes are 10%.
    2.  Log in to the system as an Event Manager.
    3.  Navigate to the "Gaming Convention" event details page.
    4.  Note the initial "Revenue Generated" (should be $0 if no tickets have been sold).
    5.  As a simulated user, purchase 5 tickets for the "Gaming Convention," applying the "EARLYBIRD" discount code during the purchase process for each ticket. Record the amount paid.
    6.  As a simulated user, purchase 5 tickets for the "Gaming Convention", without applying a discount code during the purchase process for each ticket. Record the amount paid.
    7.  Refresh the "Gaming Convention" event details page.
    8.  Verify the "Discount Usage" data.
    9.  Verify the "Revenue Generated" data.
    10. Update the tickets price to $100.
    11. Verify "Revenue Generated" is accurately reflected based on the new price.
*   **Expected Result:**

    1.  Step 4: The initial "Revenue Generated" is $0.
    2.  Step 5: Each ticket should be discounted by 20%, and the user should be charged $40 per ticket with early bird discount.
    3.  Step 6: Each ticket should be charged $50 per ticket without any discount.
    4.  Step 8: The "Discount Usage" data should accurately reflect that the "EARLYBIRD" code was used 5 times.
    5.  Step 9: The "Revenue Generated" should be calculated as `(5 tickets * $40/ticket)+ (5 tickets * $50/ticket) = $450 + tax($45) = $495`. The displayed revenue should be $495.
    6.  Step 11: The "Revenue Generated" should be calculated as `(5 tickets * $80/ticket)+ (5 tickets * $100/ticket) = $900 + tax($90) = $990`. The displayed revenue should be $990.
*   **Priority:** High
