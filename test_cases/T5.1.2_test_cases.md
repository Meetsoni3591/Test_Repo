# Test Cases for T5.1.2 - User Status Lifecycle

Okay, here are two detailed test cases covering the user status lifecycle, based on the provided task. I've tried to cover both a positive and a negative (or boundary) scenario, keeping in mind common areas where issues can arise in user management systems.

**Test Case 1: Successful Activation of an Invited User**

*   **Title:** Verify Invited User Successfully Activates Account and Becomes Active Member

*   **Description:**  This test case verifies the successful activation process for a user who has been invited to the system.  It validates that the user can successfully claim their account, create a password, and transitions into the 'Active Member' status, allowing them to access the system's features.

*   **Steps:**

    1.  **Prerequisites:**
        *   A new user account has been created in the system and is currently in the 'Invited' status.
        *   The user has a valid email address associated with their 'Invited' account.
        *   The user has received the invitation email with the activation link.
    2.  **Action:**
        *   Open the invitation email in the user's email inbox.
        *   Click on the activation link provided in the email.
        *   The system should redirect the user to the account activation page.
    3.  **Action:**
        *   On the account activation page, enter a valid and strong password in the 'Password' field.  (e.g., at least 8 characters, including uppercase, lowercase, number, and special character).
        *   Confirm the password in the 'Confirm Password' field, ensuring it matches the first password entered.
    4.  **Action:**
        *   Click the 'Activate Account' or similar button.
    5.  **Action:**
        *   (Optional) Upon successful activation, attempt to log in with the newly created password.

*   **Expected Result:**

    1.  The activation link should successfully redirect the user to the account activation page.
    2.  The system should validate the password and confirmation password fields, preventing activation if they do not match or do not meet the password complexity requirements (if any).
    3.  Upon clicking 'Activate Account', the user should be redirected to a success page or the login page.  A success message should be displayed (e.g., "Your account has been successfully activated.").
    4.  The user's status in the system should be updated to 'Active Member' or equivalent. This can be verified by an admin through the user management interface.
    5.  The user should be able to successfully log in to the system using their newly created password.
    6.  The invitation email should be invalidated and not allow the user to activate the account again.

*   **Priority:** High

**Test Case 2: Attempt to Activate an Account with an Expired Invitation Link**

*   **Title:** Verify System Prevents Account Activation with Expired Invitation Link

*   **Description:** This test case verifies that the system correctly handles expired invitation links and prevents unauthorized account activation attempts. This is a crucial security measure.

*   **Steps:**

    1.  **Prerequisites:**
        *   A new user account has been created in the system and is currently in the 'Invited' status.
        *   The user has a valid email address associated with their 'Invited' account.
        *   An invitation email with the activation link has been sent to the user.
        *   The system has a defined expiration time for invitation links (e.g., 24 hours, 7 days).
        *   Wait for the invitation link to expire based on the system's expiration policy.
    2.  **Action:**
        *   Open the invitation email in the user's email inbox.
        *   Click on the activation link provided in the email (which is now expired).
    3.  **Action:**
        *   If the system redirects to the account activation page anyway, attempt to enter a password and confirm it, then click "Activate Account".

*   **Expected Result:**

    1.  Upon clicking the expired activation link, the system should **NOT** redirect the user to the account activation page.
    2.  Instead, the system should display an error message indicating that the invitation link is expired or invalid.  The message should be clear and user-friendly (e.g., "This invitation link has expired. Please contact your administrator to request a new invitation.").
    3.  If the system does redirect to the account activation page, after the user enters a password and clicks 'Activate Account', the system should display an error message indicating that the invitation link is expired or invalid.
    4.  The user's status should **NOT** be changed to 'Active Member'. The user should remain in the 'Invited' status.
    5.  No new account should be created using the expired invitation.
    6.  Attempting to log in should fail.

*   **Priority:** High
