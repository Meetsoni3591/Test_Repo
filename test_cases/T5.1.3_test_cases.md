**Test Case 1: Event Attendance and Venue Tracking Accuracy**

*   **Title:** Verify Event Attendance and Venue Visit Recording

*   **Description:** This test case verifies that the system accurately records events a user attends and the venues they visit within their user history. This ensures that the user history accurately reflects the user's engagement with the platform.

*   **Steps:**

    1.  **Pre-Condition:** Ensure a valid user account exists and is logged in. Ensure at least one event and one venue exists in the system.
    2.  **Navigate:** Navigate to the event listing page.
    3.  **Attend Event:** Find an event and register the user for the event (if registration is required). Alternatively, if there's a simple "Mark as Attended" functionality, use that.
    4.  **Navigate:** Navigate to a venue listing page.
    5.  **Visit Venue:** If applicable (e.g., if there's a "Check-In" functionality at a venue), check the user into the venue. If no "Check-In" option exists, simulate a visit (e.g., by viewing the venue page).
    6.  **Navigate:** Navigate to the user's profile or account page.
    7.  **Access User History:** Find and access the "User History" section.
    8.  **Verify Events Attended:** Check the list of "Events Attended" in the User History.
    9.  **Verify Venues Visited:** Check the list of "Venues Visited" in the User History.

*   **Expected Result:**

    *   The "Events Attended" section should accurately list the event the user registered for/marked as attended, including the event name, date, and venue.
    *   The "Venues Visited" section should accurately list the venue the user checked into/visited, including the venue name, date, and any relevant details (e.g., number of visits).
    *   The dates of the visits should be logged correctly.
    *   If there are multiple visits to the same venue, the history should either show each individual visit or reflect the total number of visits.

*   **Priority:** High (P1) - Accurate tracking of user activity is crucial for data analysis, personalized recommendations, and understanding user behavior.

**Test Case 2: Total Spend Calculation and Referral Tracking**

*   **Title:** Validate Total Spend Calculation and Referral Tracking

*   **Description:** This test case validates that the system correctly calculates the total amount of money a user has spent on the platform and accurately tracks referrals they have made.

*   **Steps:**

    1.  **Pre-Condition:** Ensure a valid user account exists and is logged in. Ensure the platform supports transactions/purchases and has a referral program.
    2.  **Make Purchase:** As the user, purchase a product, service, or ticket through the platform. Record the price of the purchase.
    3.  **Make Another Purchase (Optional):** Repeat step 2 to make a second purchase of a different amount.
    4.  **Generate Referral Link:** Generate a unique referral link for the user.
    5.  **Share Referral Link:** Share the referral link with another user (a test account).
    6.  **New User Registers:** Using the referral link, create a new user account (the referred user).
    7.  **Referred User Makes a Purchase (Optional):** Have the newly created referred user make a purchase.
    8.  **Navigate:** Navigate to the original user's profile or account page.
    9.  **Access User History:** Find and access the "User History" section.
    10. **Verify Total Spend:** Check the "Total Spend" value in the User History.
    11. **Verify Referrals Made:** Check the "Referrals Made" section in the User History.

*   **Expected Result:**

    *   The "Total Spend" value should accurately reflect the sum of all purchases made by the user.
    *   The "Referrals Made" section should accurately reflect the number of users who registered using the user's referral link. The "Referrals Made" section could also have a list of users who signed up using their referral.
    *   If the referral program offers rewards for successful referrals, ensure the rewards are correctly applied to the referring user's account.
    *   The "Total Spend" should accurately reflect any referral bonuses/discounts.

*   **Priority:** High (P1) - Correct calculation of financial data and accurate referral tracking are essential for business operations, revenue reporting, and managing the referral program.
