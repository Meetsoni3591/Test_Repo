# Test Cases for T5.1 - User Profile Management

Okay, here are two detailed test cases for the "User Profile Management" task, designed from a Senior QA Engineer's perspective:

**Test Case 1:  Valid Profile Update - Basic Information**

*   **Title:** Update User Profile with Valid Basic Information (Name, Email)

*   **Description:**  Verifies that a user can successfully update their profile with valid information for basic fields like first name, last name, and email address. This test focuses on positive path validation and checks if the update is correctly reflected in the system and displayed to the user.

*   **Steps:**

    1.  **Pre-condition:** The user must be logged in and have access to their profile page.
    2.  Navigate to the "My Profile" page.
    3.  Locate the "Edit Profile" or similar button/link and click it.
    4.  In the "First Name" field, enter a valid first name (e.g., "Jane").
    5.  In the "Last Name" field, enter a valid last name (e.g., "Doe").
    6.  In the "Email Address" field, enter a valid email address format (e.g., "jane.doe@example.com").
    7.  Leave other fields as is, if they are not part of this specific test.
    8.  Click the "Save Changes" or similar button.
    9.  Observe the confirmation message (if any) that the profile has been updated.
    10. Verify that the "First Name", "Last Name" and "Email Address" are updated correctly.

*   **Expected Result:**

    *   The user's profile page should display the updated first name, last name, and email address.
    *   A success message (e.g., "Profile updated successfully") should be displayed to the user.
    *   The updated information should be stored correctly in the database (this might require backend verification, depending on test access).
    *   The user should remain on the "My Profile" page (or be redirected to it) after the update, and the page should refresh with the new values.

*   **Priority:** High

**Test Case 2: Invalid Profile Update - Email Format Validation**

*   **Title:** Invalid Profile Update - Email Format Validation

*   **Description:** This test verifies that the system correctly validates the email address format during profile updates and prevents users from saving invalid email addresses. It checks for common email format errors and ensures appropriate error messages are displayed.

*   **Steps:**

    1.  **Pre-condition:** The user must be logged in and have access to their profile page.
    2.  Navigate to the "My Profile" page.
    3.  Locate the "Edit Profile" or similar button/link and click it.
    4.  In the "Email Address" field, enter an invalid email address (e.g., "jane.doe").
    5.  Click the "Save Changes" or similar button.

*   **Expected Result:**

    *   The system *should not* allow the user to save the profile with the invalid email address.
    *   An appropriate error message should be displayed to the user, indicating that the email address is not in a valid format (e.g., "Please enter a valid email address").  The error message should be clear and easy to understand.
    *   The error message should be displayed near the "Email Address" field to provide context.
    *   The focus should remain on the "Email Address" field, so the user can easily correct the error.
    *   The system should not make any unnecessary calls to the backend.

*   **Priority:** High
