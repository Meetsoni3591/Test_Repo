**Test Case 1: Successful User Invitation and Activation**

*   **Title:** Verify Successful Invitation and Activation of a New User

*   **Description:** This test case verifies that a new user can be successfully invited to the system, receives the invitation email, and is able to activate their account and log in.

*   **Steps:**

    1.  **Precondition:** Ensure a user with permission to invite new users is logged into the system.
    2.  Navigate to the "Users" or "Administration" section of the application.
    3.  Click on the "Invite User" or "Add User" button.
    4.  Enter the following valid information for the new user:
        *   First Name: [Enter a unique first name, e.g., "TestUser1"]
        *   Last Name: [Enter a unique last name, e.g., "InviteTest"]
        *   Email Address: [Enter a valid and accessible email address that hasn't been previously used in the system, e.g., "testuser1.invitetest@example.com" (use a valid testing email service)]
        *   Role: [Select a valid role, e.g., "Editor"]
    5.  Click on the "Send Invitation" or "Create User" button.
    6.  **Post-Invitation:** Verify the email address in the interface shows a status of "Pending Invitation" or similar.
    7.  **Email Client Check:** Access the email inbox associated with the email address entered in Step 4.
    8.  Verify that an invitation email has been received.
    9.  Open the invitation email and verify the following:
        *   The "From" address is the expected sender address.
        *   The subject line is appropriate (e.g., "Invitation to [Application Name]").
        *   The email body contains a personalized greeting.
        *   The email contains a clear "Activate Account" button or link.
    10. Click the "Activate Account" button or link in the email.
    11. This should redirect to the account activation page within the application.
    12. On the activation page, enter a valid password and confirm it.  The password should adhere to any defined password complexity requirements (e.g., minimum length, special characters, etc.).
    13. Click the "Activate Account" or "Set Password" button.
    14. After successful activation, the user should be automatically logged in or redirected to the login page.
    15. If redirected to the login page, enter the email address used in Step 4 and the password created in Step 12.
    16. Click the "Login" button.

*   **Expected Result:**

    1.  A new user invitation is successfully sent.
    2.  The user's status reflects "Pending Invitation" in the system.
    3.  The invitation email is received within a reasonable timeframe (e.g., within 5 minutes).
    4.  The invitation email contains the expected information.
    5.  Clicking the activation link redirects the user to the account activation page.
    6.  The user is able to set a valid password.
    7.  The user's account is successfully activated.
    8.  The user is successfully logged into the system after activation.

*   **Priority:** High
