# Test Cases for T5.3.1 - Referral Dashboard

Okay, I'm a Senior QA Engineer. Based on the provided task, here are two detailed test cases focusing on different aspects of the "Referral Dashboard".  I've tried to cover both positive and negative aspects within the constraints of the limited task description.

**Test Case 1:  Referral Network Display Accuracy**

*   **Title:** Verify Correct Display of Referral Network on Dashboard

*   **Description:** This test case verifies that the Referral Dashboard accurately displays the user's referral network, including the relationships between referrer and referred users.  It checks for completeness, correctness of links, and proper display of user details.

*   **Steps:**

    1.  **Login:** Log in to the application as a user with an established referral network (e.g., "User A" who has referred multiple users, and those users may have referred others).  (Ensure you have test data pre-configured for this scenario).
    2.  **Navigate to Dashboard:** Navigate to the "Referral Dashboard" section of the application.
    3.  **Review Displayed Network:** Carefully examine the displayed referral network graph or list. Check the following:
        *   **Referrer-Referral Links:** Verify that each user who was referred by "User A" (or any user higher up in the chain) is correctly linked to them.  Ensure the direction of the link is accurate (referrer points to the referred user).
        *   **User Details:** For each user in the network, verify the displayed information is correct, including:
            *   Username/Nickname
            *   Email Address (if displayed)
            *   Date of Referral (if displayed)
            *   Any other relevant user data presented on the dashboard.
        *   **Network Depth:** If the network has multiple levels of referrals (User A refers User B, and User B refers User C), ensure the depth of the network is displayed correctly.  All referred users, regardless of level, should be displayed.
        *   **Missing Users:**  Search for known users within "User A's" referral network (based on pre-existing data). Verify that these users are visible on the dashboard.
    4.  **Logout:** Log out of the application.

*   **Expected Result:**

    *   The Referral Dashboard displays a complete and accurate representation of "User A's" referral network.
    *   Each user who was directly or indirectly referred by "User A" is displayed.
    *   Referrer-referral links are correct and point in the correct direction.
    *   Displayed user details are accurate and match the information stored in the user database.
    *   There are no missing users from the known referral network.
    *   The dashboard should load within an acceptable timeframe (e.g., less than 5 seconds).

*   **Priority:** High

**Test Case 2: Conversion Rate Calculation and Display**

*   **Title:** Verify Accurate Conversion Rate Calculation and Display on Referral Dashboard

*   **Description:** This test case verifies that the Referral Dashboard accurately calculates and displays the conversion rate for referred users.  Conversion rates can be determined by sign up, first purchase or whatever defined conversion is set.

*   **Steps:**

    1.  **Login:** Log in to the application as a user with a history of referrals (e.g., "User B"). Ensure some of the referred users have converted, and some have not.
    2.  **Navigate to Dashboard:** Navigate to the "Referral Dashboard" section of the application.
    3.  **Identify Key Users:** Identify several (at least 3-5) referred users from the displayed network. Note their conversion status (converted or not converted) based on your test data or backend database check.
    4.  **Record Dashboard Conversion Rate:** Note the overall conversion rate displayed on the Referral Dashboard for "User B".
    5.  **Manual Calculation:** Manually calculate the conversion rate for "User B's" referred users based on your known conversion status.  For example:
        *   If "User B" referred 10 users and 3 converted, the manual conversion rate is 30%.
    6.  **Compare Results:** Compare the conversion rate displayed on the dashboard to the manually calculated conversion rate.
    7.  **Test with Zero Conversions:**  Create a test user ("User C") who has referred users, but none of them have converted.  Login as "User C" and verify the dashboard displays a 0% conversion rate.
    8.  **Test with 100% Conversion:** Create a test user ("User D") who has referred users, and all of them have converted. Login as "User D" and verify the dashboard displays a 100% conversion rate.
    9. **Edge Case: No Referrals:** Create a test user ("User E") who has referred no one. Verify the dashboard doesn't error out, but rather shows a relevant message (e.g. "You haven't referred any users yet").  Also, verify that conversion rate related metrics are not displayed or show N/A or similar.
    10. **Logout:** Log out of the application.

*   **Expected Result:**

    *   The conversion rate displayed on the Referral Dashboard matches the manually calculated conversion rate based on the number of referred users who have converted.
    *   The dashboard correctly displays a 0% conversion rate when none of the referred users have converted.
    *   The dashboard correctly displays a 100% conversion rate when all referred users have converted.
    *   The dashboard handles the scenario where a user has no referrals without errors and provides a user-friendly message.
    *   The conversion rate should be displayed in a clear and understandable format (e.g., percentage).

*   **Priority:** High
